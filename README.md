# Pixabay Flutter App

Мобильное приложение на Flutter с бесконечной лентой изображений

## Функционал
- загрузка изображений из Pixabay
- бесконечная прокрутка
- Masonry Grid
- кастомный Top Bar
- кастомный Bottom Navigation Bar
- Dio для работы с сетью

## Важно — замените API Key
- Приложение использует Pixabay API.
- apiKey = 'PIXABAY_API_KEY'


## Запуск проекта
- flutter pub get
- flutter run
